Activar el servicio de Siri

Este trabajo se hace una sola vez. Después, cada usuario vincula su iPhone desde SmartHub.

1. Base de vinculaciones

En Cloudflare → Storage & databases → D1, crea smarthub-siri-links. Abre su consola SQL, pega la estructura y ejecútala.

En el Worker smarthub-siri → Bindings, añade una base D1 con nombre de variable SIRI_DB y selecciona la base recién creada.

2. Clave de cifrado

En el Worker → Settings → Variables and Secrets, crea un secreto llamado SIRI_ENCRYPTION_KEY. Genera aquí su valor y cópialo solo en ese secreto.

Guarda una copia en tu gestor de contraseñas. No se almacena en esta página ni se envía al servidor. Cambiarla después invalida las vinculaciones anteriores.

3. Código del Worker

En Edit code, reemplaza el código completo del Worker de Siri y pulsa Deploy.

Conserva los secretos antiguos si aún usas atajos antiguos. El Worker de María es independiente.

4. Enlace de Atajos

Crea y prueba el atajo desde un iPhone o Mac siguiendo la guía. Compártelo mediante iCloud y guarda el enlace como variable de texto SIRI_SHORTCUT_URL del Worker.

Abrir guía del atajo

Sin ese enlace, la PWA mostrará «En preparación». El uso con el iPhone bloqueado se debe comprobar en ese dispositivo.
